# ESMAR — мобильное приложение долевого управления

Живая версия: https://mihailingggggggg-star.github.io/elite-invest-app/

Приложение для инвестиционной компании **ESMAR** (ОсОО «УК Нур Капитал»,
лицензия Финнадзора КР № 88 от 07.08.2026 на доверительное управление
инвестиционными активами).

Инвестор не покупает паи и не торгует ими: он заключает **договор
доверительного управления** на сумму, ставку и срок. Договор оформляется
быстрой офертой и подписывается цифровой подписью через подтверждение
push-уведомления. Продажа пая заменена расторжением договора.

| Кнопка «Продать» | «Расторгнуть» — заявление с расчётом возврата и удержания |

| Оранжевый Elite Invest, Manrope | Хвоя `#232B1D`, бронза `#BB7A36 → #BB9868 → #E4D8CA`, Inter, логотип ESMAR |
| Вход сразу в портфель | Неавторизованная зона → проверка личности (KYC) при первой покупке |
| — | Экран загрузки с логотипом, push-подписание договора, калькулятор дохода, этапы стройки |

Логика экранов и навигация сохранены: нижний таб-бар с центральной кнопкой
пополнения, главная → каталог → карточка объекта, аналитика, профиль.
Нижние листы, стеклянные поверхности и все мелкие элементы взяты из
существующего набора компонентов проекта (`Glass`, `Sheet`, `Brand`,
`TabBar`, `Icons`, `Seg`) — новых визуальных паттернов не вводилось,
добавлены только блоки на тех же токенах.

## Логика долевого управления

**Продукты** (условия с esmar.kg):

| Продукт | Ставка | Срок | Выплата | Мин. сумма |
| --- | --- | --- | --- | --- |
| Рента | 15% годовых | 1 год | ежемесячно | $100 |
| Девелопмент | до 30% годовых (20 / 25 / 30% за 1 / 2 / 3 года) | 1–3 года | в конце срока | $100 |
| Партнёрство | до 55% годовых | 1 год | в конце срока | $1 000 000 |

**Путь покупки:**

1. Сумма договора (для девелопмента — выбор срока, ставка меняется вместе с ним).
2. **Быстрая оферта** — карточка с суммой, ставкой, сроком, датой окончания и долей в объекте.
3. **Подписание** — на устройство приходит push-уведомление, подтверждение ставит цифровую подпись; договор получает номер `ES-2026-XXXX`.
4. Договор появляется в портфеле, в карточке объекта и в графике выплат.

**Начисления** считаются по простой ставке от даты договора
(`src/lib/app.ts`): `сумма × ставка × дней / 365`. У «Ренты» выплаченная
часть вычитается из начисленного и попадает в свободные средства.

**Расторжение** (`termination()`):

- Рента — возврат тела и начисленного за фактический период, выплаченный доход не пересчитывается.
- Девелопмент — до срока удерживается 5% суммы, начисленный доход не выплачивается; после срока возвращается всё.
- Партнёрство — по согласованию сторон, прибыль распределяется по результатам этапа.
- Возврат на личный счёт — до 10 рабочих дней.

Все ставки, суммы и графики в приложении демонстрационные; реальные
условия фиксируются договором.

## Неавторизованная зона и проверка личности

До проверки личности доступны главная с оффером компании, каталог, карточки
объектов и новости. Первое нажатие «Купить», «Расторгнуть» или
«Пополнить» открывает проверку личности; после неё отложенное действие
продолжается автоматически.

KYC — полная эмуляция в четыре шага: данные → документ → селфи → проверка.
Камера снимает документ в рамке и селфи в овальной маске с анимацией
сканирования; если камера недоступна или доступ запрещён, шаг остаётся
рабочим — файл можно загрузить с устройства. Снимки никуда не отправляются:
демонстрация обрабатывает их на устройстве.

Графики вынесены в отдельный чанк и грузятся при открытии аналитики,
проверка личности — при первом нажатии «Купить».

**Фишки под долевое управление:**

- Push-подписание договора с печатью, датой и временем — «цифровая подпись» вместо кнопки «купить».
- Оферта как документ: сумма, ставка, срок, дата окончания, доля в объекте (`1% = $8 000`).
- График выплат по договору: ближайшие три платежа у «Ренты», дата и сумма расчёта у остальных.
- Карточка договора: номер, тело, начислено, стоимость позиции, дата окончания.
- Калькулятор дохода внутри карточки объекта.
- Полоса этапов стройки (котлован → передача ключей).
- Ставка девелопмента от срока: 1 / 2 / 3 года → 20 / 25 / 30%.
- Партнёрство с порогом $1 000 000 ведёт к менеджеру, а не в тупик.
- Лента операций: подписания, начисления, выплаты — сходится с портфелем.

## Дизайн

Домашний экран повторяет референс заказчика: крупный баланс по центру,
таблетка с приростом, карточка личного счёта вместо банковской карты,
три быстрых действия, лента последних операций и плавающая панель навигации
на пять позиций с круглой заливкой активного раздела.

Палитра и типографика — с esmar.kg:

- тёплый градиент на весь экран: хвоя `#0B0E06` → бронза `#6F4C26`;
- бронза `#BB7A36 → #BB9868 → #E4D8CA` — логотип, ставка, прогресс;
- кремовый `#F1E7D6` — активная навигация и главные кнопки;
- Inter 400–800, числа — табличные.

Все поверхности — полупрозрачные карточки с бортиком и размытием, как в
референсе. Тёмная и светлая темы, русский и кыргызский (кыргызские термины —
с кыргызской версии сайта: ижара, өнөктөштүк, келишим, ченем, мөөнөт).

Логотип — тот же контур, что в шапке esmar.kg (один path, viewBox `0 0 586 149`).
Эмблема для сплэша и печати — тот же path, обрезанный viewBox-ом `0 0 149 149`.

## Разработка

```sh
npm install
npm run dev          # http://localhost:5173/elite-invest-app/
npm run build        # tsc -b && vite build
npm run lint         # oxlint
GH_TOKEN=<токен с правом repo> npm run deploy
```

Камера работает на `localhost` и по HTTPS. В остальных случаях проверка
личности автоматически предлагает загрузку файла.
